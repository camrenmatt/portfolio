# Learning Rust
In my final semester, for my Fundamentals of the Programming Language course, I was tasked with selecting a new programming language to pick up and learn from scratch. For this endeavor I quickly selected Rust, having remembered hearing much of its importance during my internship the previous summer. Due to the nature of this course, I was also made to experimented with a variety of other languages I had never touched before (those experiments to be shown in other sections of this portfolio), which left me with little more than two weeks to build an understanding of rust deep enough to give a twenty minute presentation. The files attached below are the code snippets generated in my learning process, as well as the finished presentation. Rust is a language I intend to continue learning, and as that process continues those files will be present as well.
