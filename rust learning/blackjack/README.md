# Blackjack Program Overview
In my attempt to relearn and progress my studies with Rust I have decided to code some games within it. I chose this because the code would have a concrete goal in mind, would be easily testable, and would be familiar to my family members for said testing. The initial hope was to design a poker program, but that felt too large a leap for my first go-around, so I have opted for the more simple Blackjack. It took about a half hour or so to write V1.

# Running the Program
For initial setup you should run **cargo add rand** in the command line, as to ensure it isn't missing from the Cargo.toml file, although this shouldn't be needed using the supplied version. It plays simply, prompting command line input from the user, and rejecting invalid responses. Enjoy!
